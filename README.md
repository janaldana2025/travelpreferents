# Travel Preferents

Aplicación Android desarrollada en Kotlin que muestra sitios turísticos destacados de diferentes ciudades del mundo:

- **Barcelona**
- **París**
- **Roma**
- **Tokio**

## Características

- Visualización de información turística de cada ciudad.
- Interfaz intuitiva y fácil de usar.
- Compatible con dispositivos Android.
- Videos mostrando los paisajes más importantes de cada ciudad.

## Instalación

1. Clona el repositorio:

    ```bash
    git clone https://github.com/janaldana2025/travelpreferents
    ```

2. Abre el proyecto en Android Studio.
3. Compila y ejecuta la aplicación en tu dispositivo o emulador.
